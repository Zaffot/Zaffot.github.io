# Ruutuaika

Mobiili-ensin tehty, selaimessa toimiva ruutuajan motivaattori.

## Ominaisuudet

- 30 minuutin päivittäinen ruutuaika (muutettavissa asetuksista)
- automaattinen uusi päivä paikallisen kellonajan mukaan
- käynnistettävä ja tauotettava ajastin
- vanhemman −10, −5, +5 ja +10 minuutin pikapainikkeet
- 30 päivän paikallinen historia ja yhteenveto
- tiedot säilyvät saman laitteen selaimessa (`localStorage`)

## Julkaisu GitHub Pagesiin

Kopioi tämän kansion kolme sivutiedostoa (`index.html`, `styles.css`, `app.js`) haluamaasi alikansioon GitHub Pages -repositoriossa. Sivusto ei tarvitse käännösvaihetta tai palvelinta.

Huomaa: tiedot ovat laite- ja selainkohtaisia. Ne eivät synkronoidu automaattisesti vanhemman ja lapsen eri puhelinten välillä.
